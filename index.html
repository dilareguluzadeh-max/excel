Exam rules
  1. The exam is taken in full-screen mode.
  2. Switching to another window or tab (including Alt+Tab), minimizing the browser, leaving full-screen mode or refreshing the page counts as a rule violation.
  3. On the third violation the exam is cancelled automatically and the result is recorded as 0 points.
  4. Ctrl+C / Ctrl+V work only inside the exam: you can copy and paste spreadsheet cells (relative references shift like in Excel), but pasting text from outside or copying tasks out of the exam is not possible. Right-click and the browser developer tools are blocked.
  5. Each page contains one task. You can move between tasks at any time — your work is saved.
  6. Every task has a spreadsheet editor (formula bar, fill, number formats, Data Validation, Conditional Formatting, PivotTable, Chart). Use the “Check” button to test your solution — a partially correct solution earns partial points.
